DGIWG GeoPackage Validator v1.64

Operational pre-validation for DGIWG STD-DP-19-005 v1.1. The tool produces per-file HTML/JSON reports and batch HTML/CSV rollups.

Scope: This tool does not issue DGIWG or OGC certification. Requirements 1, 2, and 6 need external evidence. Requirements 8 and 18 retain explicit external ATS/schema work even after their automated screening passes.

1. Create the dedicated environment

Open Anaconda Prompt. Never install these packages into the base environment.

cd /d C:\Users\Son\Documents\DGIWG\DGIWG_GeoPackage_Validator_v1.64
conda env create -f environment.yml
conda activate dgiwg
python run_local_tests.py

If the environment already exists:

conda activate dgiwg
conda env update -f environment.yml --prune
python run_local_tests.py

2. Validate GeoPackages

python DGIWG_Validator_v1_64.py C:\Data\example.gpkg
python -m dgiwg_validator --recursive C:\Data\GeoPackages
python -m dgiwg_validator --offline --no-install --quiet --output-dir C:\QA\reports C:\Data

Run without a path to open the file picker. Use --help for every option.

3. Read results correctly

Status or verdictMeaning
PASSThe implemented check completed and found no violation.
FAILThe input violates a deterministic automated check.
ERRORThe validator could not complete the check; treat the run as invalid until resolved.
PASS*No violation was found, but sampled, missing, or advisory evidence remains. Read the reason chip.
SKIPPEDNot applicable or external evidence is required.
VALIDATION ERRORAt least one internal check or file-processing error occurred.
NON-CONFORMANT (automated checks)At least one deterministic data failure was found.
PRE-VALIDATION PASSED — REDUCED COVERAGENo FAIL/ERROR, but blocking PASS* evidence gaps remain.
PRE-VALIDATION PASSED — EXTERNAL CHECKS REQUIREDAutomated checks are clean, but external requirements remain.

4. Exit codes

CodeMeaning
0No automated FAIL or ERROR.
1One or more automated FAIL results.
2Validator ERROR or a file could not be processed.

5. Build release artifacts

conda activate dgiwg
python package_release.py
pyinstaller --clean --noconfirm DGIWG_Validator.spec
dist\DGIWG_Validator_v1_64.exe --version
Outputs: dist\DGIWG_GeoPackage_Validator_v1.64.zip is the clean source release. dist\DGIWG_Validator_v1_64.exe is the separate standalone Windows executable.

6. Mandatory external completion work

  • Confirm requirements 1, 2, and 6 with the applicable authority and official evidence.
  • For Req 8, run OGC 17-083r2 TMS ATS A.1-A.16 and verify the selected well-known scale set.
  • For Req 18, run the official DGIWG DMF schema and ATS validation.
  • Review every PASS* reason and close any sampled or missing-evidence item before a formal conformity claim.
