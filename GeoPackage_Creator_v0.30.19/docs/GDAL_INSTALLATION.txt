================================================================================
GDAL Installation Guide for GeoPackage Creator v0.30.19
================================================================================

GDAL (Geospatial Data Abstraction Library) is required but cannot be 
automatically installed via pip due to system dependencies.

Choose ONE method below:

================================================================================
METHOD 1: CONDA (Recommended for Windows/Mac/Linux)
================================================================================

Prerequisites:
  - Install Anaconda or Miniconda from https://www.anaconda.com/

Steps:
1. Open Anaconda Prompt (or Command Prompt if you added conda to PATH)

2. Create a new environment:
   conda create -n geopackage -c conda-forge python=3.11 gdal

3. Activate the environment:
   conda activate geopackage

4. Install remaining dependencies:
   pip install -r requirements.txt

5. Run the application:
   python geopackage_creator_gui.py

================================================================================
METHOD 2: OSGEO4W (Windows Only - Easiest for Windows)
================================================================================

Steps:
1. Download OSGeo4W installer from:
   https://trac.osgeo.org/osgeo4w/

2. Run the installer

3. Select "Express Desktop Install"

4. In the package selection, make sure GDAL is checked

5. Complete the installation

6. Open "OSGeo4W Shell" (created in Start Menu)

7. Navigate to your GeoPackage Creator folder:
   cd C:\Users\YourName\Documents\Geopackage_Creator\GeoPackage_Creator_v0.30.16

8. Install dependencies:
   pip install -r requirements.txt

9. Run the application:
   python geopackage_creator_gui.py

================================================================================
METHOD 3: SYSTEM PACKAGE MANAGER
================================================================================

Ubuntu/Debian:
  sudo apt-get update
  sudo apt-get install gdal-bin python3-gdal python3-pip
  pip install -r requirements.txt

macOS (with Homebrew):
  brew install gdal
  pip install -r requirements.txt

================================================================================
VERIFICATION: Check GDAL Installation
================================================================================

To verify GDAL is properly installed:

  python -c "from osgeo import ogr; print('GDAL version:', ogr.GetDriverCount())"

If you see a number, GDAL is installed correctly.
If you see an error, try one of the installation methods above.

================================================================================
TROUBLESHOOTING
================================================================================

Error: "ModuleNotFoundError: No module named 'osgeo'"
→ GDAL is not installed. Use one of the methods above.

Error: "The specified module could not be found"
→ Windows PATH issue. Use OSGeo4W Shell instead of regular Command Prompt.

Error: "GDAL library not found"
→ GDAL version mismatch. Try updating:
  conda update -c conda-forge gdal
